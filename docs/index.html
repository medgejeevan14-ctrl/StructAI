What it explores

A more transparent design workflow

StructAI combines an explicit calculation workflow with explanatory assistance, so users can inspect the engineering logic rather than treating an AI response as the source of design values.

01 / CALCULATE

Beam design checks

Python-based calculations for supported rectangular, singly reinforced reinforced-concrete beam cases under the current project scope.

02 / REVIEW

Code-aware audit

Present calculation checks and compliance-related results in a structured workflow that is easier to review.

03 / EXPLAIN

AI-assisted explanations

Use AI to explain results and concepts without allowing the explanation layer to change numerical calculation outputs.

Scope and limitations

Clear boundaries matter.

StructAI is an early-stage engineering software project, not a substitute for professional engineering judgement or an independently verified design package.

Important: Independently verify calculations, assumptions, detailing, load combinations, and applicable code requirements before using any result in practice.

Current stated scope

  • IS 456:2000 rectangular singly reinforced beam design workflow.
  • AI-assisted explanation kept separate from numerical outputs.
  • Doubly reinforced beams and flanged T/L beams are outside the current supported scope.
  • Combined torsion design is not implemented.

Refer to the repository documentation for the latest implementation details and test instructions.
